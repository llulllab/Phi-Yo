The missing layer

Coherent inner life is not a longer context window.

A robot, a companion device, a wellness platform, a conversational product, each of these increasingly needs a coherent inner life. Today, builders reach for the closest available substitute: prompt scaffolding, short-term memory buffers, sentiment classifiers stacked together. The result is plausible turn-to-turn behaviour with structural inconsistencies at scale. The fiftieth conversation is not informed by the forty-nine that came before it.

The missing layer is not a model. It is a theory. Freud for Machines is that theory, returned to Freud directly, recovered from a secondary literature that had mystified it, and rendered as a computational ontology. Phi-Yo is the first product that resolution made possible.

What Phi-Yo is

The product, and the foundation underneath.

Phi-Yo is a computational psychoanalytic wellbeing companion. It runs as a live consumer product at phi-yo.app and as an integration-ready backend for third-party platforms. Phi-Yo v2 has been in production since 26 April 2026, with a native mobile release (iOS and Android) following in May 2026.

Freud for Machines is the formal ontology beneath the product: concepts, premises, propositions, and transpositions that constrain every interpretation Phi-Yo produces. The framework is what makes outputs structurally consistent across modes, across users, and across time. It is not separately licensable; it is available exclusively through Phi-Yo integration.

Four temporal modes

Each mode addresses a distinct moment in the user's day.

Each mode is exposed as an integration endpoint, and each draws from a single shared profile rather than building its own.

α
Wellbeing
Multi-turn psychoanalytic conversation on everyday inner life. The mode for present-moment reflection.
β
Morning Teller
A forward-looking morning brief, drawn from the user's recent psychological history and the day's planned context.
γ
Daily Check-in
A backward-looking reflection at the end of the day. One prompt, capturing what occupied the user's mind.
δ
Dreams
Theory-grounded dream interpretation, accumulated across the user's full dream history.
Persistent profile

The continuity layer no host could practically build alone.

A single per-user profile underwrites every mode. Four components, all longitudinal:

Context (life situation, current concerns), affective history (recurring emotional patterns and their evolution), personal symbol map (a user-specific map of recurring images with their frequency, contexts, and evolving meaning), and a monthly pattern report synthesizing all four modes.

This is the integration's most valuable asset. Any host platform that integrates Phi-Yo inherits a continuity layer that cannot be replicated through longer context windows or ad-hoc memory buffers. Phi-Yo also generates natively in nine languages (English, French, German, Spanish, Japanese, Russian, Arabic, Chinese, Turkish), with automatic detection.

Integration model

A small public surface, by design.

Partners receive four endpoints, a memory layer, and the framework that makes both consistent. The integration packet is delivered at the NDA stage; what follows is the public summary.

Endpoints
One per mode. Each accepts user identifier, interaction content (text or transcribed speech), and optional session context. Each returns theory-grounded interpretive text, structured metadata (symbols, affects, themes), and the updated profile state.
Memory
Persistent per-user, shared across all four endpoints, held server-side. The host does not manage memory.
Latency
Typical response in single-digit seconds per call.
Data residency
EU-resident, GDPR-aligned.
Ethical bounds
Probabilistic language, no diagnosis, professional referral when patterns are concerning. These constraints apply at every endpoint, for B2C and B2B traffic alike.
Three deployment scenarios

The same backend, three classes of host.

Humanoid and companion robots

The four modes map onto the robot's daily relationship cycle. Morning Teller orients the user to the day. Wellbeing carries the exchanges throughout it. Daily Check-in closes it. Dreams handles the morning conversation about the night before. The robot's voice, body, and persona remain the manufacturer's. The interior-state layer is Phi-Yo.

Wellness platforms

Consumer wellness products typically operate stateless from session to session. Phi-Yo supplies the longitudinal interior layer that enriches each surface the host already operates. The host retains its brand and interface; Phi-Yo supplies the interpretive engine and the continuity.

Hardware and companion devices

Embedded companion devices, from desktop companions to home-resident agents, can integrate Phi-Yo as the depth layer that distinguishes a sustained user relationship from a recurring novelty. The four modes scale to the device's interaction footprint without losing the longitudinal benefit.
